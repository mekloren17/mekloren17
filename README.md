### Featured projects

**[Polimi MedTech Transfer Map](https://github.com/mekloren17/polimi-medtech-transfer-map)**: which medical technologies patented at Politecnico di Milano are not (yet) becoming companies, and which Italian startups work close to them. Independent research built only on open data. **[Open the interactive map →](https://mekloren17.github.io/polimi-medtech-transfer-map/)**

- 117 Polimi medtech patent families compared with 417 Italian innovative startups, read from their own websites.
- Multilingual sentence embeddings over Italian and English texts, with the terms that explain every link.
- A similarity threshold calibrated on labelled pairs (precision, recall, AUC), with the limits stated openly.
- Results published as an interactive d3 map that highlights the gaps: orphan technologies and startups with no visible tie to Polimi.

**[Team Builder](https://github.com/mekloren17/team-builder)**: a web app that builds balanced teams for weekly 5-a-side and 7-a-side football, live and being tested with a group of about 50 friends.

- Player ratings start from a questionnaire and are designed to learn from match results.
- An exhaustive search over every possible split proposes the fairest teams, with the win probability for each side.
- The rating method was chosen with a **Monte Carlo simulation** (30 groups × 200 matches) comparing Elo variants with a full-history regression model.
- Built with Next.js, TypeScript and Supabase (row level security on every table), deployed on Vercel, with automated tests and CI.
